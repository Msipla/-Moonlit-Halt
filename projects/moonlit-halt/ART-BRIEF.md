# 《月下小站》美术迭代范围

基于用户 v1.0 / v2.0 执行任务书与两张 iQOO 15 实机截图整理。截图本身未随本次源码导入获得可读取的原始图片文件，因此不在仓库中冒充原图备份；现有代码、v1 备份和实际渲染对比均随工程提供。

## 核心方向

黑暗维多利亚的画面，温柔童话的灵魂。19 世纪英国乡间铁路小站，在深蓝黑色永夜里仍被正常使用。建筑有煤烟、风化、磨损和维护的痕迹；情绪安静、古老、柔和，不是恐怖、废墟或末日。

玩家从原有乡间小路接近车站，感受到「这里很偏僻，很安静，但有人在等下一班火车」。保持车站、职工小屋、短铁路与站台、少量煤气灯、草地、树木、远山和缓慢煤烟的原有规模。

## 五项主要反馈

| v1 问题 | 迭代目标 |
| --- | --- |
| 建筑过于简单、规整 | 提升屋顶、檐口、山墙、门窗石饰与结构合理的铸铁雨棚；仍是一座小站。 |
| 暖光太亮、照射范围太大 | 低亮度琥珀色灯火，局部衰减；保留大量柔和可辨识的暗部。 |
| 月亮灰暗 | 清晰银白月亮，适度月面细节；冷色月光成为主要照明，不照成白天。 |
| 材质平整、干净 | 暗红褐砖、冷灰石、板岩、木纹和暗铁；克制的煤烟与工业使用痕迹。 |
| 风格组合不统一 | 用统一色彩、材料、比例与光照组织整体画面；远景清晰，不靠浓雾遮挡。 |

## 必须保留与不增加

保留手机触屏移动与视角、自由漫游、基础碰撞、位置重置、环境声与开关、标准/省电画质、横屏适配。

不增加场景区域、大型建筑、NPC、室内、运行列车、任务、战斗、经济、天气、昼夜循环或 Minecraft MOD 资产。精度优先于规模。

## 验收边界

主要设备为用户的 iQOO 15 / Android 浏览器。目标为流畅的 60 FPS 体验，允许适当提高模型与材质品质，不要求追求 120 FPS 或原生物理分辨率。实际设备指标必须实测，不能从桌面离屏渲染推断。

美术检查优先看出生点、正面和站台近景的实际画面与同视角对比。当前完成项与未验证项以 [TEST-REPORT.md](TEST-REPORT.md) 为准。
