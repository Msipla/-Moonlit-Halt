# 月下小站 · Moonlit Halt

## 项目定位
独立、可漫游的小型 3D 美学原型，以维多利亚月夜车站为主题。目标是验证自然语言指导下的 AI 场景设计、建模、材质、灯光和迭代能力，**不是** Minecraft 地图或 MOD。

## 既定方向
- 小规模、高精度，不以扩展玩法或地图面积为本阶段目标。
- 优先提升建筑、材质与光照的艺术品质。
- 主要体验设备：Android 手机浏览器（iQOO 15）。
- 评估应以实际运行、手机端画面和交互体验为准。
