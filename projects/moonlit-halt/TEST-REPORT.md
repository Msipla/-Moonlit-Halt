# 月下小站 v2.0 验证与美术修改记录

日期：2026-10-11。项目定位：小型 3D 艺术原型。本阶段未增加区域、NPC、室内、火车运行或玩法。

## 验证来源区分

| 来源 | 已确认的范围 |
|---|---|
| 用户提供的 v1.0 手机截图与反馈 | iQOO 15 浏览器能加载、移动、转向及播放环境声；截图曾显示约 120 FPS。未进行严格性能测试。 |
| 本次 Node 逻辑与几何测试 | v2.0 初始化、有限几何、相机、移动、碰撞、摇杆、指针取消、拖动视角、重置、画质切换。DOM / GL 使用替身。 |
| 本次 Mesa EGL / OpenGL ES 离屏绘制 | 实际编译全部 6 个着色器，链接 3 个程序；绘制捕获的天空、静态场景、透明烟及站牌。每次绘制 GL 错误码为 0。不是浏览器测试。 |
| 实际画面查看 | 查看出生点、正面、站台近景、竖屏画面和 v1/v2 相同相机对比，据此修正暖光、砖块比例、屋面法线、雨棚柱距、煤烟和材质采样。 |

## 五项反馈对应修改

| 用户反馈 | v2.0 对应处理 |
|---|---|
| 建筑粗糙 | 原主体大小不变；改纵向屋顶与窄入口山墙；新增分片板岩、层叠檐口、石材窗饰、面板门和细铸铁雨棚。 |
| 暖光过亮 | 改用有限半径、边缘衰减的点光，窗户和灯罩独立减亮；超出半径后不再给墙面叠加暖光。 |
| 月亮灰暗 | 月亮使用独立银白发光处理与原创月面纹理；与建筑的色调映射分开，避免被压成灰片。 |
| 材质缺少历史感 | 引入原创轻量材质图集；细砖与灰缝、煤烟沉积、石材变化、木纹与维护过的氧化铁件。 |
| 风格不统一 | 统一煤烟红褐砖、冷灰石、板岩蓝灰、暗绿铁与低亮琥珀；小屋和近景设施沿用这套关系。 |

## 实际通过的检查

- `node --check dist/scene.js`。
- `node tests/check-scene.cjs`：完整生成 219,824 个静态三角形，顶点数据 29,016,768 字节；几何及相机为有限数。8 项交互/逻辑检查通过。
- 标准模式在 1280×720 下渲染出生点、车站正面与站台近景；以同一相机坐标、视角、画幅和 12 秒时间点绘制 v1.0，形成对比。
- v2.0 720×1280 竖屏比例的原生离屏渲染通过；此项仅检查 3D 画面比例，不验证 DOM 横竖屏布局或真实触屏。
- 6 个着色器、3 个程序在原生 GLES 中实际编译/链接通过；合成纹理、静态几何、烟雾和站牌各绘制通道没有 GL 错误。
- 三份原创纹理使用 2 的幂尺寸，满足 WebGL 1 的 mipmap 限制。纹理都随项目提供，不依赖外部域名。
- v1.0 HTML、CSS、JS 及原始 ZIP 保持逐字节一致，可独立启动。

图像在 `dist/studies/`。它们是实际程序几何、着色器与资源绘制的像素读取，非概念图、非 AI 生成替代图，未对画面进行调色或美化。对比拼图只缩放和加标签。

## 未验证

- v2.0 在真实 iQOO 15 / Android 浏览器中的加载、实际 WebGL 执行、双指输入、声音、屏幕旋转及长时间漫游。
- 稳定 60 FPS、发热、耗电、显存峰值及各浏览器兼容性。
- 目标手机上最终私有站点登录及更新缓存行为。

当前环境没有 Sites 指定的浏览器控制能力，未启动浏览器 QA。原生 EGL / GLES 只能确认渲染算法在该驱动上的行为，不能替代 Android WebGL 验收。保留 v1 的用户实测结论，也不将它自动继承为 v2 的实测结论。

## 已知简化

- 建筑与网格仍为程序化风格化美术，未使用扫描资产或完整 PBR。
- 阴影是局部解析遮蔽，不是完整投射阴影；不使用夸张泛光或浓雾。
- 历史痕迹通过颜色、纹理与几何表达；没有破损、废墟或恐怖元素。
- 基础建筑碰撞不逐一覆盖所有小设施；没有室内。
- v1 原生离屏图中浏览器 Canvas 站牌由 Pillow 字体近似重绘，画面其余几何/着色器为 v1 原代码。v2 站牌使用同一源 PNG，无此差异。
- 环境声未重新录制或扩展；沿用用户已经体验的合成声实现。

## 实际查阅的建筑参考

不是精确复建以下站点；取其材料比例与结构语言，控制在原型尺度内。

- Historic England：Rainhill Railway Station（约 1860）。参考红砖/石材/板岩材料关系、檐口、木与铸铁雨棚及装饰支撑。https://historicengland.org.uk/listing/the-list/list-entry/1391885
- Historic England：Rayne Railway Station（1869）。参考乡间铁路建筑的克制比例、砖饰、石材门窗和铁路绿门色。https://historicengland.org.uk/listing/the-list/list-entry/1425096
- Historic England：Clare Station（1865）。参考拱形窗头、抬高拱心石和带托件窗台。https://historicengland.org.uk/listing/the-list/list-entry/1412333
- Bluebell Railway：Horsted Keynes 雨棚修复记录（原站建于 1882）。参考铸铁柱、支架、横梁与屋面之间的结构关系。https://www.bluebell-railway.co.uk/bluebell/hkcanopy.html

## 手机验收建议

横屏打开 v2，再访问 `/v1/`；从同一出生点走到门前和站台，比较月亮、砖石、雨棚、暖光和煤烟。开启声音并尝试省电模式。连续漫游数分钟后，记录帧率、操作是否粘连、是否出现黑屏或明显发热。该步骤完成后才能补充真实设备性能结论。
