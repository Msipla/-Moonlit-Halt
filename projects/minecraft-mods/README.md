# Minecraft MOD 实验区

**目标平台（当前设想）：Minecraft Java 1.20.1。** 每个 MOD 作为独立子项目；具体使用 Fabric 或 Forge/NeoForge、版本依赖和兼容性均需在开发时单独确认。

## 创意候选（尚未实现）
- **深海城市：** 大型水下城市，深渊、海底巨构与安全观察危险的氛围。
- **抽卡成长：** 钻石资源抽卡、命座／专武式成长、意外稀有奖励。
- **空间与景观：** 微光洞穴、阈限空间、遥远地平线与巨构视觉体验。

这些是独立的创意方向，**不等于已经立项为同一个整合包，也不代表已有代码或模型**。

## 项目建立规则
每个实际启动的 MOD 新建自己的目录，记录目标游戏版本、加载器、依赖、构建命令、可运行验证、性能与已知问题。可借鉴《月下小站》的美术研究，但不要混合两套工程资源。
