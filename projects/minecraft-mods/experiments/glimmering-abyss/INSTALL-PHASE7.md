## 在正常主世界游玩

1. 创建普通地形的主世界。后台按世界种子寻找有足够山体覆盖、未居住的完整位置，随后逐区块建成一处景观。首次选址需要数分钟；无需生成命令或跨维度传送。
2. 景观准备完成后，在不同夜晚正常入睡并睡到天亮。第一次梦见蓝色巨柱与暖窗，第二次获得「微光回响」。后续睡眠可补领遗失的回响；也可用指南针与紫水晶碎片合成。
3. 在主世界手持回响右键使用。短暂的微光轨迹和方向、距离提示指向山间站台的地表阶梯落点；回响可反复使用。
4. 沿带侧栏的短阶梯走进站台，右键触碰灯旁的回响铃，坐进封闭玻璃车厢。中立幻翼牵引车厢沿固定路线下降，约 45 秒到达地下观景平台。
5. 沿现有步道、铁桥与街道探索六栋建筑的小镇。回到地下站台，触碰同样的回响铃，即可返回地面。

车厢同时容纳一位玩家。途中潜行会提前返回出发站台；路线受阻或旅行中断时也回到安全站台。幻翼是随车的无攻击演出模型，没有原版幻翼的攻击 AI。

## 生成和安全范围

每个普通世界选择一处稀有景观，位置随种子变化。洞厅、巨柱、桥梁、深渊和小镇仍是 Phase 6 已交付的整体，只为正常世界高度平移并小幅补充岩台外围岩体。地表入口是唯一计划中的地面开口；检查失败会跳过候选，不切穿地表硬放。超平坦等不适合地形安全跳过。

景观记录写入存档，完成后不会在重启时重建，玩家改动可以保留。首次生成仅选择未居住区块；接入已有存档时仍建议先在副本查看结果。安装到已探索很多的存档可能找不到满足全部覆盖条件的位置。

整个洞厅、深渊、桥梁、街道、入口和竖井都排除普通怪物及其他生物，进入范围的生物也会移除。保护不依赖画面亮度，不改变全局难度或 `doMobSpawning`；景观以外的主世界保留正常刷怪。不要将宠物带入该范围。

冷蓝光在景观内部自动启用，保持已认可的 `blue` 基准与原生暖窗亮度。地面和其他主世界区域不应用景观空间光。

## 研发与复现

旧 `/abyss enter`、`/abyss town`、`/abyssrender` 等实验维度命令保留。它们是历史研发入口，生存旅行使用主世界站台。

```bash
./gradlew --no-daemon build stageTestMods
xvfb-run -a python3 -u tools/run_phase7.py --accept-eula --skip-build --output evidence/phase7/new-unique-run
```

无需重新运行 `author_town.py`，Phase 6 已交付的 NBT 直接作为资源使用。使用独立测试存档和新的证据目录。测试专用命令仅在 `-Dabyss.testServer=true` 隔离服且有操作员权限时开放。

Windows/PCL2、目标 GPU、Sodium/Iris/Distant Horizons、第三方光影及长时多人负载尚未验证。空间光仍没有完整墙体遮挡，暖窗仍为原有不透明发光立面。本阶段没有 NPC、战斗或新增剧情系统。
