## 已完成的源码研究

The Betweenlands 的 `1.12-fixes` 分支，固定研究快照 `eafac1c217cdf304d477b025708e0dadf82b6953`：

| 文件 | 观察与取舍 |
| --- | --- |
| `api/misc/Fog.java`、`FogState.java` | 将距离、颜色、密度及目标状态分开，逐 tick 更新并在帧间插值；借鉴分离参数与平滑过渡，不沿用洞穴缩短可见距离的数值 |
| `client/handler/FogHandler.java` | 生物群系、区域、液体和事件共同选取环境状态；借鉴维度／区域作用范围，舍弃浓雾事件及药剂等玩法依赖 |
| `common/world/WorldProviderBetweenlands.java` | `generateLightBrightnessTable` 和 `updateClientLightTable` 区分客户端亮度表与世界光照；借鉴显示亮度与传播的分工，不直接移植旧 `WorldProvider` |
| `common/world/biome/BiomeBetweenlands.java` | 生物群系提供环境 RGB 与距离；本轮先固定一个测试区域，不扩展生态系统 |
| `ShaderHelper.java`、`postprocessing/WorldShader.java`、`world.fsh` | 深度重建、多光源和帧缓冲链可以提供更多效果，但旧 Forge、GL 状态与专用 G-buffer 不适合直接复制；本轮不引入这一整套系统 |
| `ground_fog.fsh` | 有高度／体积雾实现，本项目的当前目标不需要，明确不采用 |

源码入口：<https://github.com/Angry-Pixel/The-Betweenlands/tree/eafac1c217cdf304d477b025708e0dadf82b6953>。采用自己的 Fabric 1.20.1 实现，没有复制其源码或美术资源。

## 正在实现的路线（此节是开发进度，不是测试通过声明）

- A：直接保留原版光照显示与距离状态。
- B：维度限定的轻微冷色 lightmap 底光，叠加缓慢的暗色距离混合，近处不做遮挡。
- C：在 B 的同一底光上限制最大距离混合量，保留远处岩体与空腔的对比度。先检验现有巨柱，不为了截图新造建筑。
- 仅现有发光块的表面添加很小、经过深度测试的冷色标记，增强尺度线索，不改变 5 级光传播，不做泛光。
- 同一世界／同一进程里拍摄 A/B/C；增加无光源的 B/C 对照，检查环境可见度是否独立于测试灯；额外检查返回主世界后是否恢复原版。
- 核对版本固定的 Yarn `LightmapTextureManager`、`BackgroundRenderer`、`RenderLayer` 与 Fabric 客户端事件接口。旧 Forge 事件不参与本实现。
