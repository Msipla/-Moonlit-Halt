## 新景观与旧存档

自然洞穴、七栋房屋、桥对岸阅览庇护所、住宅楼梯/床铺和小水池用于**7.5新生成的景观**。新建普通主世界最适合验收新地貌；不要使用超平坦。

已经生成Phase7景观的存档继续保留原景观、原缆车路线和玩家改动，**不会自动覆盖或自然化旧景观**。旧档可使用状态提示、短暂梦境画面与车辆插值。不要为了看新地貌删除旧世界或已有景观记录。

## 正常生存流程

后台寻找完整山体和未被使用的区域，逐区块生成。景观就绪后，在两个不同夜晚正常入睡：醒来时分别看见2秒洞穴/暖窗实景画面，然后继续留在床边。它是静态梦境，不是跨维度传送。

获得或合成寻梦微光后，右键查看生成状态或定位入口。沿阶梯抵达站台，右键回响铃登车；地下段有横向出游，再落到熟悉的观景台。沿原步道和铁桥进入小镇及对岸阅览室，再乘车返回。途中潜行提前回到出发站台。

## 创造模式快速验证

这些命令仅创造模式玩家可用，不需要测试服务器启动参数。没有重建/覆盖景观命令；生成未完成前不会给出候选坐标或传送玩家。

| 命令 | 用途 |
| --- | --- |
| `/abyss debug status` | 查看选址、覆盖检查、生成进度、停止原因和梦境进度 |
| `/abyss debug entrance` | 仅在生成完成后安全定位地表站台 |
| `/abyss debug town` | 仅在生成完成后安全定位地下站台 |
| `/abyss debug dream 1` | 预览第一段静态梦境，不改正常睡眠进度 |
| `/abyss debug dream 2` | 预览第二段静态梦境，不改正常睡眠进度 |
| `/abyss debug ride` | 在已生成站台附近测试乘车 |

安卓验收建议：先看状态，再定位入口并完整往返一次；重点观察地下横向运动时是否仍抖、两段梦境能否完整显示、岩台/底面是否自然、过桥能否进屋、住宅楼梯与床铺、池水是否留在池内。如果怀疑某块未渲染，保留现场截图和 `latest.log`；不要先认定是生成缺块。

## 已知范围

局部禁怪包含全部景观及入口，不改变主世界其他区域的刷怪。车厢仍为固定线路、一次一人；上部穿越入口竖井，横向观景发生在地下段。暖窗保持旧发光立面，空间光仍没有完整墙体遮挡。本阶段不加入NPC、敌对生物、战斗、大片地下海洋或全球地形替换。

真实安卓Amethyst的最终乘坐舒适度、显示兼容性和审美结论由用户验证；托管Linux客户端结果不能替代手机实测。Windows/PCL2、Sodium/Iris/DH、第三方光影及长时多人负载亦不在已验证范围。

## 开发复现

已提交生成好的NBT，普通构建无需重新生成素材。使用Java 17：

```bash
./gradlew --no-daemon build stageTestMods
xvfb-run -a python3 -u tools/run_phase75.py --accept-eula --skip-build --output evidence/phase75/new-unique-run
```

实跑脚本用于Linux隔离测试世界，包含正常世界生成、官方发布客户端与专用服、真实停服重启和旧版升级；依赖首次按官方来源下载。每轮使用新证据目录。需要改建筑时再运行 `python3 tools/author_natural_town.py`；它只生成新的稀疏模板，不改历史 `town.nbt`。
