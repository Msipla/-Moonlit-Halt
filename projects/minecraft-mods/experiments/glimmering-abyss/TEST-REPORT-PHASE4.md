## 实际完成

一栋原创双层深色砖石工坊、坡屋顶、拱窗、两座烟囱、小塔楼、支承平台与带护栏连接步道。少数不透明暖窗提供原版12级光；烟囱营火实际产生烟雾，室内有工作台、储物与少量灯光。没有村民、常驻 NPC 或模板实体；没有废墟/怪物系统。

采用原生标准 NBT 模板，20,039 个明确位置含净空。`/abyss building` 在现有实验维度显式加载，适用于新/旧研究存档，也可重复放置；模板与构造脚本可独立替换。Terrain 与 ChunkGenerator、第三阶段光照参数和历史入口保持；铜金能力仍可测试，但不是当前推荐地下色调。

连接步道在旧观景台右侧打开一处通道，属于本阶段有意新增结构。不能把放置后的世界指纹称为完全不变；**放置前**实测指纹与 Phase 1/3 基线一致。所有旧原图、JAR、报告与 URL 保留。

## 性能及未测

llvmpipe (LLVM 20.1.2, 256 bits)，托管 Linux 软件 OpenGL。建筑机位短时约12.65–24.79 FPS，P95约45.01–88.49ms；原始CSV与逐帧JSON全部保留。不是目标 GPU 成本测量，不宣称稳定60 FPS。

Windows/PCL2、目标 GPU、长时漫游/内存、Sodium/Iris/Distant Horizons、透明材质及实体/粒子的完整空间光一致性尚未实测。托管机没有 OpenAL 音频设备，错误日志保留，声音听感未验证。环境光沿用 Phase 3 未计算完整墙体遮挡的近似，室内光场泄漏仍存在；窗格为不透明模型避免引入未验证玻璃管线。

## 失败与恢复

- 本地 Java 下载 Gradle 网络不可达，改用独立 GitHub 环境；没有修改用户系统。
- 38246690747：构建与原生光/地形检查通过，发布客户端加载包和空间着色器后没有进入服务器，900秒超时。修正依赖开发类名字符串的启动引导判断；失败日志和包保留。
- 38248948976：已进入游戏并完成采集，但路线采样穿门柱、后墙中心边界过严导致验收失败。由于原 runner 在复制前断言失败，该轮原PNG未归档，只保留日志中的捕获记录；已修正失败时也保留原图/参数的流程。
- 中间待执行/无效运行由并发规则替换，取消记录保留；最终38250075059独立重新构建、安装、采集和重启，通过后才选为交付证据。
