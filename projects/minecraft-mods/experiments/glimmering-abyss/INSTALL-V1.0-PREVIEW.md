## 玩家流程与快速审查

景观就绪后，在两个不同夜晚实际睡眠。梦境在睡眠中淡入，醒来淡出，保留离床按钮；第二晚得到寻梦微光，右键引导到入口。循灯抵达站台，右键回响铃进入缆车；地下靠站轨迹平滑横移到主镇南侧，乘车返回地表。潜行用于提前回到出发站台。

创造模式可用`/abyss debug status`、`/abyss debug entrance`、`/abyss debug town`快速查看状态/定位已完成的景观。这些定位命令不会重新生成景观。不要用`/abyss phase7`等仅隔离测试服务端可用的命令作为普通安装说明。

加速睡眠检查时可以开启命令并使用原生`/time add 24000`，核对新日数，再定位到该日夜晚；随后用生存模式真实睡眠。反复`/time set night`和梦境预览命令都不能代替跨日/真实睡眠验证，详细规范见报告。

本轮重点审查右侧岩壁/洞顶的自然程度、四处生活建筑及街巷是否融入岩台、密度是否舒适。原七栋/桥/图书馆保持；新添烘焙屋、织工作坊、两处住宅和公共雨棚，实际生存街巷Y45–48。审图查看[本轮原图目录](evidence/v1/runs/38500421865/screenshots/)，其中全景/东侧街巷/公共空间/住宅室内已复查。整体空间此前有条件认可，本轮未替用户作最终美学结论。

安卓Amethyst仍需真实实测：睡眠画面与按钮、缆车往返/抖动、疑似缺块、步道和房屋可达性、帧率及发热。托管Linux成功不代表手机通过。保留现场截图与latest.log，便于核对。

## 正式1.0前的实机验收准备

preview.2已获得有条件审图认可；本轮有限收尾将提供新的原图和校验包，最终美学仍需确认。以下真实安卓Amethyst检查不由Linux自动化代替。先备份旧档，在独立普通新世界使用本轮推荐包；保持设备常用渲染设置，记录Amethyst/Java/渲染器版本、手机型号、视距和是否启用第三方光影。

1. 生成就绪后查看聚落全景、东壁与洞顶；走入四处新建筑及岩台支巷，确认有留白、头部净空、舒适高差和可辨返回路线。顺路走完折向廊返回镇内。
2. 生存模式在两个不同游戏日的夜晚真实睡眠，观察睡眠期间梦境的淡入/停留/醒后淡出、离床按钮和第二晚微光授予。命令可用于推进日数，但不替代床铺交互和实际睡眠；避免重复set night停在同一日。
3. 从入口实际乘缆车下降并返回，观察横向靠站的连贯性、抖动、异常显示、碰撞和安全落站；再次登车后潜行提前下车，再确认可重新登车。
4. 保存退出后重入同一世界，确认建筑、路面、灯光、玩家改动和抵达状态保持；保留旧世界仅换包，确认既有景观未被重铺。
5. 同设置在镇内和外围各正常停留/行走约五分钟，记录常见及最低FPS、区块加载是否卡顿、明显发热/闪退。截图和latest.log保存原件；不能仅用静态全景判断手机性能。
