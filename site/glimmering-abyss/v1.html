这次修复了什么

  • 追踪孤立微光石的旧校准坐标，修正无条件放置；新景观仅在连通天然岩体内嵌入。
  • 局部调整洞壁、岩台与附壁巨柱的生成几何，保留巨大落差、冷蓝环境和暖窗。
  • 十一栋建筑按实际用途补充室内陈设，疏通门口和楼梯。
  • 利用已有岩廊设置断层观测停留位、下层远端及回镇指引，环线的去程和归途都有明确节点。

发现、抵达、返回

  1. 在普通主世界中正常生活，等待后台选址和景观生成。
  2. 景观准备好后，在两个不同游戏日的夜晚实际睡眠，积累梦境线索并取得寻梦微光。
  3. 手持微光右键定位入口，在站台触碰回响铃乘坐幻翼缆车。
  4. 抵达后探索街巷、室内和外围岩廊，沿东侧回程坡返回小镇。
  5. 在地下站台触碰回响铃回到地面；途中潜行可提前返回出发站。

安装与旧存档

Minecraft Java 1.20.1、Java 17、Fabric Loader 0.14.25、Fabric API 0.85.0+1.20.1。备份存档后替换旧 JAR，客户端和服务端保持同版，每个实例只保留一个微光深渊版本。

旧景观和玩家改动保留，不自动重铺。查看本轮岩壁、室内与探索修复，请另建普通新世界。本轮验证种子为 74102002 和 -92345；生成需要数分钟，设备不同会有差异。
