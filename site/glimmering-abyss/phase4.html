安装与进入

Minecraft Java 1.20.1、Java 17、Fabric Loader 0.14.25、Fabric API 0.85.0+1.20.1。将 v0.4.0 与 Fabric API 放进实例的 mods 文件夹，只安装一个本 MOD 版本。在开启作弊的测试世界使用：

  1. /abyss enter 进入现有实验维度。
  2. /abyssrender blue 选择已认可的冷蓝方向。
  3. /abyss building 放置或重新加载工坊与步道。
  4. /abyss building view facade 到达建筑观景位置；可以沿步道走进工坊。
  5. /abyss return 返回主世界。

其他建筑机位：warmth、scale（创造模式）、bridge、interior。第三阶段的 /abyss view 与 /abyssrender a/copper 继续保留。

技术证据与已知限制

本轮使用官方 Minecraft 发布客户端与 Fabric，实际加载打包后的 MOD JAR；正式服务端也加载同一 JAR。保留放置、重复加载、保存重启、原生光级和实际行走的记录。
