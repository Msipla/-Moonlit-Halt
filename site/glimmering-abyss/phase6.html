街道很近，深处很远。

一条短主街、小广场、六栋不同轮廓的建筑。已认可的工坊与暖窗继续留在岩台上，外围仍是巨大冷蓝洞厅与巨柱。平缓街区在陆架边缘突然下沉，原铁桥连接对岸观景台；北侧小塔可以登上，越过屋顶看深渊。

安装与进入

Minecraft Java 1.20.1、Java 17、Fabric Loader 0.14.25、Fabric API 0.85.0+1.20.1。将 v0.6.0 与 Fabric API 放入实例 mods 文件夹，每次仅保留一个本 MOD 版本。在开启作弊的测试存档中：

  1. /abyss enter 进入实验洞厅。
  2. /abyssrender blue 使用现有冷蓝环境光。
  3. /abyss town 放置小镇与局部断崖地形。
  4. /abyss town view street 到达主街；向北行走，经过两级缓台阶，到小塔入口后沿内侧木梯登上观景层。
  5. /abyssrender blue95 或 /abyssrender blue95-fog 切换实验；/abyssrender blue 恢复基准。
  6. /abyss return 返回主世界。

落地机位：street、plaza、high、cliff、bridge、scale、facade、interior。overview 为创造模式远景。

本阶段仍使用研发维度。放置会替换模板范围内的地形、手动改动与容器状态，使用测试存档。

实测证据与限制

真实发布版客户端与服务端加载同一打包 JAR。逐项记录原生光级、模板状态、实际过桥与街道行走、登梯、碰撞、重复放置和同存档重启。所有原图未经提亮或调色。

有限底面仍位于 y=-63，部分角度可能看见底部；不宣称无限深渊。高度渐变为地形表面混合，并非完整体积雾。托管 Linux 软件 OpenGL 已测；Windows/PCL2、目标 GPU、真实手机、Sodium/Iris/Distant Horizons、透明窗与长时性能尚未验证。整个实验景观区域都禁止普通怪物与其他生物生成；原版攻击型幻翼不放行。未来中立景观幻翼待后续开发。小镇没有常驻 NPC，钟面是静态装饰。
