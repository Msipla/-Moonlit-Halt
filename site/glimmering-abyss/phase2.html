A / B / C 同机位比较

三套方案都使用原生 5 级微光源。B 与 C 的环境底光相同，区别集中在距离衰减；渲染距离、视角、时间和地形保持一致。

三套机制与核心参数

方案环境底光距离混合局部微光
A · 原版基线完整保留原版 lightmap；Gamma 0.5原版距离参数，实际值见截图记录保留原生 5 级传播；关闭额外表面光斑
B · 自然空间层次显示底光 RGB 系数 0.36 / 0.40 / 0.44；随方块光级增加而减弱24–224 格；暗蓝黑 RGB 0.006 / 0.009 / 0.013；最大混合 0.92既有光源面上 0.28 格的小光斑，系数 0.48；无泛光
C · 巨构远景与 B 完全相同36–360 格；暗蓝黑 RGB 0.012 / 0.018 / 0.026；最大混合 0.64，保留至少 36% 输入色与 B 完全相同

距离混合借用原版 terrain shader 的 smoothstep 和 fogColor.a，不添加可见雾粒子、不覆盖整套 shader、不降低区块渲染距离。环境底光只改变客户端显示，不增加世界内的方块光或天空光。

运行与溯源

安装 Java 17、Minecraft 1.20.1、Fabric Loader 与匹配的 Fabric API，将 v0.2 JAR 放入 mods。单人世界打开作弊后：/abyss enter → /abyss light glimmer → /abyss view platform。用 /abyssrender a、b、c 切换对照；/abyss return 返回主世界。完整复现脚本见 README。
