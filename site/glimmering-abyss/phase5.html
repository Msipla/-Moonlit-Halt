安装与进入

Minecraft Java 1.20.1、Java 17、Fabric Loader 0.14.25、Fabric API 0.85.0+1.20.1。将 v0.5.0 与 Fabric API 放进实例的 mods 文件夹，只安装一个本 MOD 版本。在开启作弊的测试世界使用：

  1. /abyss enter 进入现有实验维度。
  2. /abyssrender blue 选择已认可的冷蓝方向。
  3. /abyss route 放置或重新加载工坊、有限竖井、铁桥和俯瞰台。
  4. /abyss route view departure 到达路线起点；沿铁桥走向远端小观景台，再回望工坊。
  5. /abyss return 返回主世界。

核心机位：core、down、arrival、span（创造模式）、facade、interior。第三阶段的 /abyss view 与 /abyssrender a/copper 继续保留。

技术证据与已知限制

本轮使用官方 Minecraft 发布客户端与 Fabric，实际加载打包后的 MOD JAR；正式服务端也加载同一 JAR。保留放置、重复加载、保存重启、原生光级和实际行走的记录。

竖井底面为 y=-63，步行面为 y=39；这是有限空间。重复放置会重置模板范围的手动改动与容器内容，使用测试存档。托管 Linux 软件 OpenGL 已测；Windows/PCL2、目标 GPU、真实手机网页和 Sodium/Iris/Distant Horizons 尚未实测。窗口为首版不透明立面模型；空间光仍不计算完整墙体遮挡，音效与长时性能不在已通过范围中。城市自然生成、梦境探索和缆车属于后续设计。
