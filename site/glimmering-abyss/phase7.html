PHASE 07 / 真实客户端原图

从山间，慢慢抵达暖窗。

睡梦里的一声铃响，掌心一束指路的微光。找到主世界群山中的站台，乘坐特殊幻翼牵引的玻璃车厢，穿过岩层，抵达熟悉的冷蓝洞厅与六栋建筑的小镇。探索之后，同一座缆车会带你返回地面。

正在读取第七阶段实跑证据。

发现、抵达、返回

  1. 在普通主世界中正常生活；后台寻找有完整山体覆盖的位置。
  2. 景观准备好后，在两个不同夜晚睡到天亮，获得梦境线索与微光回响。
  3. 手持回响右键，循微光轨迹与距离提示找到山间站台。
  4. 触碰灯旁的回响铃登车。封闭座舱沿固定路径下降，约 45 秒到达地下。
  5. 步行游览街道、铁桥和洞厅，再触碰地下站台的铃返回地面。途中潜行可提前返回出发站台。

整个洞厅、深渊、小镇与抵达路线都属于安静的安全景观。主世界其他地方继续正常刷怪。幻翼为无攻击的随车演出模型，车厢一次承载一位玩家；没有战斗、NPC 或繁琐任务链。

保留已经认可的小镇

六栋建筑、街道、暖窗和冷蓝光沿用第六阶段成果。此次只小幅补充岩台外围的岩体轮廓，并适配主世界的山体覆盖与底部高度。第六阶段原图及光照对照完整保留。

安装与进入

Minecraft Java 1.20.1、Java 17、Fabric Loader 0.14.25、Fabric API 0.85.0+1.20.1。客户端与服务端安装同一 v0.7.0 JAR，每个实例只保留一个微光深渊版本。普通生存旅行无需作弊命令。
