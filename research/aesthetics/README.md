# 美学研究索引

本目录存放跨项目可复用的审美研究、视觉参考及实验记录，不直接作为任何项目的正式素材或世界设定。

## 当前方向
- **安全地观察危险：** 隔着玻璃、屏障或安全空间凝视深海、洞穴与巨物，重点是神秘感和尺度感，不以惊吓为目标。
- **梦核与阈限空间：** 熟悉却不完全真实的空间、微弱灯光、朦胧与留白。
- **巨构与远景：** 远处可见、难以立即抵达的庞大建筑或地貌。
- **月夜维多利亚建筑：** 《月下小站》的建筑比例、材质、月光和灯光设计。
