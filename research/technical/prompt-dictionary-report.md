## 数据格式与去重

顶层 `format=prompt-dictionary`、`version=1`，`columns` 指定每行位置：

| 列 | 含义 |
|---|---|
| `tag`、`zh` | 原始英文主标签、选用的来源译名；不改写英文为场景描述 |
| `source_category` | 原来源的 0 通用 / 1 画师 / 3 作品 / 4 角色 / 5 元数据；缺失为 null |
| `count`、`source_counts` | 排序频次及各来源频次。优先 ffdkj，其次 TagComplete，最后 wfjsw；缺失时排序按 0，UI 标为未知 |
| `aliases` | 来源提供的英文别名及归并前拼写；保留而不凭空补造 |
| `group` | 本项目的展示分类；与原始类别严格分开 |
| `source_mask`、`translation_source` | 来源位掩码和译名来源；位号 ffdkj=0、TagComplete=1、Physton=2、wfjsw=3 |
| `flags`、`source_groups` | 可解释的敏感/风险规则标识，以及 wfjsw 原分类路径 |
| `alternate_zh` | 其他来源的不同译文；不直接删除冲突释义，仍参与检索 |

按英文的小写、空白/下划线等价键合并，原始主标签优先保留 ffdkj 的原文，其余拼写放入别名。去除 1 个无效/空记录，合并 236,508 次重复出现。**独立核对 SQLite 的 336,155 个主标签，缺失 0 个。** 没有设置图数阈值删掉已取得的有效标签。

原始类别冲突 274 次，全部记录在 `conflicts.categories`；优先 ffdkj 的类别。不同来源频次全部留存，不能把老来源数值解释成实时图数。不同译名 57,827 条，完整差异留在各行 `alternate_zh`，顶层另保留 30 个质检样本。

## 中文质量与覆盖

含中文字符的标签 **266,692 / 343,777（77.58%）**；不含中文的 **77,085** 条。后者包含画师署名、日文/拉丁字母专名，不代表每条都应强行汉译。通用标签中文覆盖更高：

| 原始类别 | 标签数 | 含中文数 | 覆盖率 |
|---|---:|---:|---:|
| 通用 | 54,451 | 53,436 | 98.14% |
| 画师 | 156,886 | 88,262 | 56.26% |
| 作品 | 20,575 | 18,488 | 89.86% |
| 角色 | 106,581 | 101,648 | 95.37% |
| 元数据 | 758 | 747 | 98.55% |
| 来源未提供类别 | 4,526 | 4,111 | 90.83% |

译名优先 wfjsw 已有展示名 → ffdkj → Physton，保留其他译法用于检索。wfjsw 没有逐词审校凭证；ffdkj 声明 AI 翻译加社区校对，但 README 正文与字段表对模型版本说法不一致；Physton 未提供逐条翻译方法或审核状态。**本轮没有逐条人工审核、没有调用翻译模型，不能把中文覆盖率当作准确率。**

实际抽查发现旧译表有错误或冗长解释，例如 `virtual_youtuber` 被译成“微博”、`hetero` 被译成“异类”；本次优先级避免优先采用该旧译文，但差异仍可追溯。来源间 `looking_at_viewer` 有“看向阅图者”/“看向观众”等差异；`1girl` 的泛称不提供可靠年龄信息。来源译名与显示分类都有进一步校对空间，不称其为权威中文词典。

“通用待分类”包括词义证据不足的条目；其中原始通用类 25,948 条。**完整保留数据不等于全部词义已完成精细语义分类**；不根据粗糙猜测强行贴标签。自定义分类为检索辅助，存在误分可能。

## 浏览器测试与性能

Chromium **153.0.8010.0**，Linux x86_64，真实浏览器 `file://` 离线加载。容器中使用 headless/single-process/disable-gpu 参数；与普通桌面浏览器进程模型有差异。移动测试是 **393×873 视口、触控模拟、页面 CPU 4× 降速**，不是 iQOO 或 Android 真机；降速也不保证同样施加到 Worker。

**38 项场景检查通过，0 个页面脚本异常**：全库 gzip 导入、中英/下划线/空格搜索、精确匹配优先、分类与原始类别、来源限制级筛选、风险只读、收藏/选择/负面内容刷新恢复、WAI/Anima 预设、TXT 下载、CSV 表头/引号/重复/跨行、错误 JSON 恢复、移除词库、MOSS 原功能、结果数量与横向溢出检查。

| 环境 | 文件选择到就绪 | Worker 加载/索引 | 普通常用/无结果查询端到端 | 宽泛 `a` 查询 | 页与 Worker 已用 V8 堆 | 加载期最大 20ms 定时器间隔 |
|---|---:|---:|---:|---:|---:|---:|
| 桌面 1440×1000 | 2.57 s | 2.39 s | 193–218 ms | 431 ms | 184.4 MiB | 138 ms |
| 移动视口 393×873，CPU 4× | 3.31 s | 2.79 s | 213–325 ms | 718 ms | 184.4 MiB | 353 ms |

端到端搜索包含 130 ms 输入防抖与界面更新；常见 Worker 查询约 43–68 ms。数字来自一次完整最终运行，不是多设备性能承诺。内存测量为 CDP `Runtime.getHeapUsage`，**不是操作系统 RSS/总峰值**；原始证据另列 committed heap 与 backing storage。加载/解压会有临时分配，低内存手机仍需真机检查。

采用 Worker 解压、解析、去重与索引；主线程只保留内置词、当前结果及选中/收藏词的小缓存。桌面最多渲染 120 条，移动视口 60 条。即便这样，降速模拟仍可出现数百毫秒的加载/宽泛查询停顿；没有宣称绝对不卡顿。完整词库不写 localStorage，刷新后重新选择数据文件；收藏与已选提示词单独持久化。

功能与数据还经过独立重建对比：同一固定输入得到完全相同的 gzip 与 HTML 字节。词库 gzip SHA-256：`79d6f31193b6d86aec5fa97db1561162c17d92583770bc1383fd56952af24572`。

## 复现与剩余边界

构建依赖 Python 3.10+、PyYAML 6；浏览器测试依赖 Node.js、Playwright 与已安装 Chromium。依赖只用于维护者复现，成品用户无需安装。

```sh
python build-prompt-dictionary.py --cache /tmp/prompt-dictionary-sources
node test-prompt-dictionary.cjs /tmp/prompt-dictionary-evidence
```

构建脚本下载固定版本并核对 blob SHA；可用 `--out-dir` 在临时目录重建比较。已更改的稳定基线会使脚本退出，要求先审查集成差异，绝不自动覆盖稳定文件。容器自定义浏览器可通过 `BROWSER_EXECUTABLE` 指定，`BROWSER_SINGLE_PROCESS=1` 启用本轮使用的容器参数。

尚未验证：真实 Android 的文件选择/下载行为、持续内存/耗电/发热、Firefox/Safari、不同浏览器 localStorage 对 file:// 的差异、剪贴板权限的各平台分支、WAI/Anima 实际生成效果。词库存在某个标签不等于模型理解它。

**最小下一步**：用户下载测试 HTML 与词库，在手机选择词库试用搜索和收藏；验收后仅把经确认的导入、Worker 搜索和导航映射补入稳定 HTML。无需改 ComfyUI、引入 API、后端、APK 或重建产品架构。测试候选在验收前保留；后续若合入稳定版，应收掉候选入口并由 Git 保留历史。
