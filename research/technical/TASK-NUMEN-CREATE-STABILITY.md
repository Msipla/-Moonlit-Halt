## 目标与边界

目标是提高 DeepSeek V4 Pro 自主 Create 改造的勘察效率、完成回执稳定性和对其他机械任务的通用性。保留上轮合并 Lua 示例已验证的机械施工、漏斗投料、自主读产物、建筑恢复、按时回复成果，保留独立验收和截止隔离。420 秒是每次模型实验的截止，不是整个 Work 阶段的截止。

首先只读分析上轮相同 Skill 一次成功一次退化的模型轨迹、工具回执及现有房主 Lua 模块，确认可复用入口和实际缺失信息。只有在确有必要时，把已验证的机械簇、局部地板范围、候选布局 diff 汇总封装为现有 Lua 模块内一次**只读、参数化、紧凑**调用；模型自行选择锚点、候选格、布局和施工。不要硬编码水磨坊坐标、替模型规划、引入独立扫描框架或改写 Numen 核心。若现有接口已经足够，优先调整调用方式，不必新增 API。避免继续堆叠 Skill 文字。

在原始相同存档、同一自然语言指令、同一模型与权限护栏下进行必要的少量对照与原样确认；保留 420 秒上限，超时后先确认代理离场且无在途写入，再独立验收。分别记录自主投料并读到**新磨石产物**、真实传动与磨粉、建筑保留、按时交付回执，以及逐格读块、Lua 调用、API 请求、token、耗时。背包旧面粉不算新产物证据；不能用验收夹具代替模型自验。区分一次成功与稳定复现，不因偶然成功扩大结论。

若同条件闭环表现获得可复现改善，再选一个**不同于水磨坊搬迁**的小型 Create 机械任务进行迁移验证；让模型自主规划，不给固定坐标或人工纠错。若无法稳定复现，则不强行迁移，说明结构性瓶颈和最小后续方案。
